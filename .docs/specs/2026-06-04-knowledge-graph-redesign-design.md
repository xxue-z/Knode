# 知识图谱 UI 重新设计

## 概述

重新设计 Wiki 模块的知识图谱 UI，使其从扁平 2D 图表升级为具有星系氛围的 3D 交互式知识地图。

## 设计目标

1. 颜色跟随 App 主题，不硬编码
2. 类目节点和文章节点使用不同图案区分
3. 支持缩放、拖动、旋转，有 3D 立体感
4. 节点标签截断，避免过长
5. 缩小后有繁星点点的星系感
6. 不同类目星系根据文章关联度自然聚散

---

## 节点设计

### 类目节点（星球）

- **形状**：圆形（星球）
- **样式**：渐变实心圆，三色渐变（亮→中→暗）
- **尺寸**：缩小 8-14px，正常 36-48px，放大 48-64px
- **阴影**：外发光（glow）+ 内阴影（立体感）
- **标签**：不截断（类目名通常较短）
- **颜色方案**（每个类目不同）：

| 类目 | 渐变色 |
|------|--------|
| 笔记 | #64B5F6 → #1E88E5 → #0D47A1 |
| 学习 | #81C784 → #43A047 → #1B5E20 |
| 工作 | #CE93D8 → #8E24AA → #4A148C |
| 灵感 | #FFB74D → #FB8C00 → #E65100 |
| 归档 | #B0BEC5 → #78909C → #37474F |

### 文章节点（双层环）

- **形状**：圆形（双层描边环）
- **样式**：外层光晕（淡色描边）+ 内层实线（较深描边）
- **尺寸**：缩小 4-6px，正常 18-24px，放大 24-34px
- **颜色**：使用所属类目的淡色（如笔记类文章用 rgba(100,181,246,0.5)）
- **标签**：固定 6-8 字符截断 + 省略号

### 双层环视觉规范

```
外层：border: 1.5px solid rgba(类目色, 0.15-0.2)
内层：border: 1.5-2px solid rgba(类目色, 0.45-0.55)
```

## 连线设计

### 类目-文章连线

- **样式**：实线
- **颜色**：类目色淡色（rgba(类目色, 0.25-0.3)）
- **宽度**：1.5px

### 文章-文章连线（标签关联）

基于 Jaccard 标签相似度计算：

| 相似度 | 样式 | 颜色透明度 |
|--------|------|-----------|
| > 0.7 | 实线 | 0.6 |
| 0.5-0.7 | 虚线 (4,3) | 0.4 |
| 0.3-0.5 | 虚线 (4,3) | 0.2 |
| < 0.3 | 不连线 | - |

连线颜色使用两个节点所属类目色的混合（或使用源类目色）。

## 背景设计

### 浅色模式

```
背景渐变：#F5F7FA → #E8EDF2 → #DFE6ED
星点颜色：rgba(180, 190, 200, 0.4-0.7)
边框：1px solid #E0E0E0
```

### 深色模式

```
背景渐变：#0f0c29 → #302b63 → #24243e
星点颜色：rgba(255, 255, 255, 0.3-0.6)
边框：无
```

背景自动跟随 App 主题切换（浅色/深色模式）。

## 星系聚类布局

### 布局算法

1. **计算跨类目关联度矩阵**
   - 对每对类目 (A, B)，统计 A 中文章与 B 中文章的标签 Jaccard 相似度均值

2. **将关联度转换为距离**
   - 关联度 0.6 → 距离 = 星系半径 × 0.5（重叠 50%）
   - 关联度 0.3 → 距离 = 星系半径 × 0.75（重叠 25%）
   - 关联度 0.0 → 距离 = 星系半径 × 1.0（边缘接触）

3. **力导向布局微调**
   - 加入排斥力避免完全重叠
   - 迭代至稳定状态

### 星系视觉

- 每个类目形成一个"星系"（带光晕的区域）
- 星系内的文章节点分布在其所属类目星球周围
- 关联度高的类目星系自然重叠，形成知识地图

## 3D 交互设计

### 手势

| 手势 | 操作 | 说明 |
|------|------|------|
| 双指缩放 | 放大/缩小 | 以屏幕中心为锚点 |
| 单指拖动 | 平移 | 有惯性滑动效果 |
| 双指旋转 | 旋转视角 | 可选功能，松手有回弹 |
| 单击 | 选中星球 | 高亮 + 显示摘要 |
| 双击 | 进入详情 | 进入类目/文档的详细视图 |

### 缩放行为

- **放大**：以屏幕中心为锚点，其他星球向屏幕外移动，中心内容逐渐放大
- **缩小**：以屏幕中心为锚点，其他星球向屏幕内聚拢，直至显示完整星空

### 缩放层级

| 层级 | 类目星球 | 文章节点 | 连线 | 标签 |
|------|---------|---------|------|------|
| 完整星空 | 8-14px 光点 | 不显示 | 淡色细线 | 不显示 |
| 中等缩放 | 36-48px | 18-24px 双层环 | 可见 | 6-8 字截断 |
| 放大聚焦 | 48-64px | 24-34px 双层环 | 清晰 | 完整显示 |

## 验证步骤

1. **代码分析**：运行 `melos analyze` 确保无静态分析错误
2. **单元测试**：运行 `melos run test` 确保所有测试通过
3. **视觉验证**：
   - 浅色模式下图谱背景为浅灰色渐变
   - 深色模式下图谱背景为深空渐变
   - 类目星球显示三色渐变
   - 文章节点为双层描边环
   - 不同类目星系有不同程度重叠
4. **交互验证**：
   - 双指缩放以屏幕中心为锚点
   - 单指拖动有惯性效果
   - 点击星球高亮并显示摘要
   - 双击进入详情视图
5. **标签验证**：文章节点标题超过 8 字符时显示省略号
